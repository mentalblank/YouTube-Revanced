# YouTube - Morphe (Auto-Build)

Patched with [morphe-patches](https://github.com/MorpheApp/morphe-patches). One universal APK covering `arm64-v8a` and `armeabi-v7a`.

## Installation

1. Download and log in to [GmsCore](https://github.com/ReVanced/GmsCore/releases/latest) / [MicroG-RE](https://github.com/WSTxda/MicroG-RE).
2. Install the latest version of [Build APK](https://github.com/MentalBlank/YouTube-Revanced/releases/latest).
3. Use [Obtainium](https://github.com/ImranR98/Obtainium) to download and install build updates.

81 of the 86 available patches are applied by default — the full list for the exact bundle used is linked in every release. The main ones:

**Layout** — Custom branding · Change header · Navigation bar options · Hide video action buttons · Hide layout components · Hide Shorts components · Change form factor · Disable layout updates · Settings menu filter

**Extras** — SponsorBlock · Return YouTube Dislike · DeArrow alternative thumbnails · External downloader support · Copy video link · Add to queue · Captions control · Open channel of live avatar · Disable rolling number animations · Disable haptic feedback

**Plumbing** — GmsCore support, which is what lets the patched app run without root under its own package name.
